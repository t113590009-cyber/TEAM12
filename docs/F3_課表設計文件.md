## 1. 功能概述
- build_schedule：輸入專案全域狀態 state、學生學號，產生該學生一週7天、每日12節的課表矩陣。
- find_free_blocks：依課表矩陣，搜尋符合條件的連續空堂區段，提供給F4活動排程使用。

## 2. 資料結構設計
### 課表矩陣 grid
- 維度：7行 × 12列
- 索引規則
  - 第一維(行)：星期，1=週一、7=週日
  - 第二維(列)：節次索引，對應PERIOD_TABLE 1‑9、a、b、c，由 period_index()轉換得到
- 格子儲存內容：
  - None：該時段為空堂
  - dict：{"type":"course","id":"課程代號"} 代表課程
  - dict：{"type":"activity","id":"活動編號"} 代表活動
