# F1 模組函式介面表（Module Interface）

模組檔：`src/f1_data.py`　負責人：組員 B　版本：v1.1
依賴：`src/common/result.py`、`src/common/validators.py`、`src/common/time_slot.py`（`check_room_conflict`、`slots_overlap`）。
所有函式皆回傳 `{ok, data, errors}`，直接修改傳入的 `state`，業務錯誤不拋例外。

| 函式 | 輸入 | 處理 | `data`（成功） | 錯誤碼與 detail |
| :--- | :--- | :--- | :--- | :--- |
| `add_course(state, course_data)` | state、課程 dict | `validate_course` 跑完全部欄位 → `check_room_conflict` → 存入標準化複本 | 課程 dict | INVALID_ID_FORMAT、DUPLICATE_ID、INVALID_FIELD、INVALID_CREDIT、INVALID_CAPACITY（含 capacity／room_capacity）、NOT_FOUND（room_id）、INVALID_PERIOD、ROOM_CONFLICT |
| `modify_course(state, course_id, new_data)` | state、課號、欄位 dict | 與原資料合併驗證 → 人數上限不低於現有人數 → 教室衝堂 → 時段變更時檢查已選學生 → 更新 | 更新後課程 | NOT_FOUND、INVALID_FIELD（改代號、改 status 或欄位不合法）、其餘同 add_course、CAPACITY_BELOW_ENROLLED（`enrolled`、`new_capacity`、`students`）、ROOM_CONFLICT、STUDENT_CONFLICT（`conflict_students`） |
| `query_courses(state, filters, include_cancelled=False)` | 條件 `course_id`／`teacher`／`day`／`category`／`has_seats`（AND） | 驗證條件值 → 過濾 → 依課號排序 → 回傳複本 | 課程清單；查無為 `[]` | INVALID_FIELD、INVALID_PERIOD |
| `cancel_course(state, course_id)` | state、課號 | 退選所有學生、狀態改 cancelled；重複取消視為成功 | `{course_id, status, removed_students}` | NOT_FOUND |
| `delete_course(state, course_id)` | state、課號 | 無人選修才刪除 | `{deleted_id}` | NOT_FOUND、COURSE_IN_USE（`course_id`、`enrolled`） |
| `list_course_students(state, course_id)` | state、課號 | 由選課紀錄推導，依學號排序 | `[{student_id, name, department}]`；無人為 `[]` | NOT_FOUND |
| `add_student(state, student_data)` | state、學生 dict | `validate_student`（學分上限預設 24） | 學生 dict | INVALID_ID_FORMAT、DUPLICATE_ID、INVALID_FIELD、INVALID_CREDIT |
| `delete_student(state, student_id)` | state、學號 | 刪除並移除其選課與活動報名 | `{deleted_id}` | NOT_FOUND |
| `add_room(state, room_data)` | state、教室 dict | `validate_room`（設備預設 `[]`） | 教室 dict | INVALID_ID_FORMAT、DUPLICATE_ID、INVALID_FIELD、INVALID_CAPACITY |
| `delete_room(state, room_id)` | state、教室代號 | 任何課程（含已取消）或活動引用就拒絕 | `{deleted_id}` | NOT_FOUND、ROOM_IN_USE（`room_id`、`courses`、`activities`） |
| `get_enrolled_students(state, course_id)` | state、課號 | 由 `enrollments` 推導 | 直接回傳排序後學號 list（非結果結構） | — |

## 共用層函式（`src/common/`）
| 函式 | 說明 |
| :--- | :--- |
| `make_ok(data)`、`make_error(code, message, detail)`、`make_result(data, errors)` | 統一回傳結構；`make_ok([])` 保留空清單 |
| `validate_course／validate_student／validate_room(state, data, is_new=True)` | 欄位驗證，回傳標準化後的新 dict；F6 載入共用 |
| `normalize_period`、`normalize_slot`、`is_int_value`、`is_valid_id` | 節次正規化與型態檢查 |
