# F1 資料模型說明（Data Model）

## 1. 實體（皆為 `dict`，存於 `State`）

### 1.1 課程 course（`State.courses[course_id]`）
| 欄位 | 型態 | 必填 | 規則 | 違反時錯誤碼 |
| :--- | :--- | :---: | :--- | :--- |
| `course_id` | str | 是 | 7 位數字 `[0-9]{7}`，不可重複、不可修改 | INVALID_ID_FORMAT／DUPLICATE_ID |
| `name` | str | 是 | 非空白 | INVALID_FIELD |
| `credits` | int | 是 | 正整數；接受 `3.0` 並存成 `3`；拒絕 0、負數、2.5、True、"3" | INVALID_CREDIT |
| `category` | str | 是 | `"required"` 或 `"elective"` | INVALID_FIELD |
| `teacher` | str | 是 | 非空白 | INVALID_FIELD |
| `capacity` | int | 是 | ≥ 1 且 ≤ 教室容量 | INVALID_CAPACITY |
| `room_id` | str | 是 | 須已存在 | NOT_FOUND（非字串為 INVALID_FIELD） |
| `slots` | list[dict] | 是 | 至少 1 筆、不可重複；`{"day": 1～7, "period": "1"～"9"／"a"／"b"／"c"}` | INVALID_PERIOD |
| `status` | str | 否 | `"active"`（預設）或 `"cancelled"`；只能經 `cancel_course` 變更 | INVALID_FIELD |

- 節次正規化：整數 1～9 與大寫字母轉成標準字串後才儲存；`d`、`0`、`10` 為非法。
- 修課人數由 `State.enrollments` 推導，不另存。

### 1.2 學生 student（`State.students[student_id]`）
| 欄位 | 型態 | 必填 | 規則 | 違反時錯誤碼 |
| :--- | :--- | :---: | :--- | :--- |
| `student_id` | str | 是 | 9 位數字 `[0-9]{9}`，不可重複 | INVALID_ID_FORMAT／DUPLICATE_ID |
| `name` | str | 是 | 非空白 | INVALID_FIELD |
| `department` | str | 是 | 非空白，如 `"資工三甲"` | INVALID_FIELD |
| `credit_limit` | int | 否 | 正整數，預設 `DEFAULT_CREDIT_LIMIT = 24` | INVALID_CREDIT |

已選課程與目前學分由選課紀錄推導，不另存欄位（資料格式書 1.3）。

### 1.3 教室 room（`State.rooms[room_id]`）
| 欄位 | 型態 | 必填 | 規則 | 違反時錯誤碼 |
| :--- | :--- | :---: | :--- | :--- |
| `room_id` | str | 是 | `R` 加 3 位數字，不可重複 | INVALID_ID_FORMAT／DUPLICATE_ID |
| `building` | str | 是 | 非空白 | INVALID_FIELD |
| `capacity` | int | 是 | 正整數 | INVALID_CAPACITY |
| `equipment` | list[str] | 否 | 元素為非空小寫字串、不重複，預設 `[]` | INVALID_FIELD |

## 2. 關聯與不變條件
- 選課紀錄：`State.enrollments` 為 `set[(student_id, course_id)]`。
- `cancelled` 課程沒有任何選課紀錄；取消後不佔教室、不計學分、預設查詢不顯示。
- 課程引用的 `room_id` 必須存在；因此 `delete_room` 只要任何課程（含已取消）或活動仍引用就回 ROOM_IN_USE（需先刪除該課程）。
- 新增與修改課程都呼叫共用層 `check_room_conflict`（只比對有效課程與有效活動）。

## 3. 回傳結構
```json
{"ok": true, "data": {}, "errors": []}
```
`errors` 每筆為 `{"code": str, "message": str, "detail": dict}`；測試只比對 `ok`、`code`、`detail`。業務錯誤不拋例外；失敗時 `data` 為 `null` 或部分結果。

## 4. 驗證函式（`src/common/validators.py`，F6 載入共用）
`validate_course`、`validate_student`、`validate_room`：只驗證不改 state，跑完全部欄位，成功時 `data` 為標準化後的新 dict。
